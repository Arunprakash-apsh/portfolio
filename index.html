How I test

A repeatable path from requirement to a confident release.

Understand the requirement

Turn requirement documents and Figma designs into clear, testable cases.

Plan the strategy

Decide what to cover with smoke, functional, regression and exploratory testing, and what to automate.

Execute and report

Run tests with Selenium, Appium, Postman and JMeter, and log defects in JIRA or Bugzilla.

Find the root cause

Trace issues across the UI, API and database, then verify the fix.
